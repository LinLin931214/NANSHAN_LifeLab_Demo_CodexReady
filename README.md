# NANSHAN LifeLab Demo（Codex Ready）

純靜態、無資料庫、手機優先。

## 執行
直接雙擊 `index.html`，或：
```bash
python3 -m http.server 8000
```
再開 `http://localhost:8000`

## 最常改
- `data.js`：事件、金額、商品範例、官方連結
- `styles.css`：介面
- `app.js`：流程與計算
- `AGENTS.md`：給 Codex 的專案規則
- `CODEX_PROMPTS.md`：可直接貼給 Codex 的修改指令
- `DEPLOY_GITHUB_PAGES.md`：固定網址上架教學

所有金額都是教育情境假設，不是實際保費、保額或理賠試算。


## 遊戲壓力與保障升級
- 每十年一關；初始保障在起點選擇，之後直接於事件頁下方調整下一個十年的種類及基本／加重／高額等級，不另開頁；調整不改變本關費用或既有給付。
- 一般風險抽選率隨年齡為47%～70%，完全未配置持續保障為64%～78%；這是遊戲難度，不是真實事故率。
- 人身保費僅依年齡段係數與等級計算，不再疊加逐年漲幅；事件費用依情境、年齡與隨機嚴重程度計算。
- 模擬給付有種類及上限限制，不對應實際南山保單報價或理賠；官方資訊入口仍保留。

驗證方式（需要 Node.js）：
```bash
node tests/challenge.test.cjs
```

平衡調整：事故基礎費用降低20%，每關風險率下調18個百分點，六關平均約少一次風險事件；保費與給付上限保持原設定。

保障比例校正：年齡費率係數為1、1.1、1.25、1.45、1.7、2；等級費率係數為1、1.35、1.75。對應保障全配時，基本／加重／高額方案最多分擔本事件60%／75%／90%，依事件資料權重分配到各類型，未選類型的份額不給付。汽車、住宅基本／加強方案為70%／85%，海外醫療為70%／90%。這些百分比僅為遊戲規則，不代表南山保單。

## 最終保障回顧
最後一頁列出每個事件的無保障自付、實際自付、使用保障與給付，以及各保險累計保費／給付。加碼試算固定原事件與房車選擇，完整計入新增保費；給付增加不等於淨省錢。各替代方案獨立，不能直接相加，且只是假設事前已配置，不能事故後補買。

最終頁將多個加碼方案合併成一組事故相關的基本保障試算：列出保障名稱、全趟保費、分擔事故費用及扣除保費的淨差額。人身保障連續計費、房車按持有月份、海外按事故旅程；實際購買紀錄改為摺疊明細。

房車遊戲價格：汽車總價100萬元、頭期款60萬元、貸款40萬元（每月7,500元，共5年，含模擬融資成本）；住宅總價1,000萬元、頭期款200萬元、房貸800萬元（每月34,000元，共30年）。售屋固定價同步為1,000萬元；保留售屋費用與未償本金清償。均為遊戲假設。

起點設定：預設每月收入50,000元，可選20～29、30～39、40～49、50～59、60～69或70～79歲開始。僅模擬選定階段以後的收支；收入與生活費以起點為基準，保費與風險依實際年齡。從60歲以上開始時，輸入收入視為退休月收入。所有新旅程均無房車，30歲後由使用者勾選購買才收頭期款及後續費用。
